# Collider Workshop V3
Unity 2D collider generator for sprites meant for Getting Over It maps.
## Installation
1. Place the `ColliderWorkshop.cs` file into your Unity project inside a folder named `Editor`
## How to use
1. Select sprite objects you want to generate colliders for (all must be on layer 10 Terrain)
2. Click menu item `Tools > Export collider workshop`
3. Open collider workshop and drag the file named `colliderworkshop.txt` into the window
4. Generate colliders by pressing G, and move to the next sprite by pressing tab
5. Press ctrl S to save
6. In Unity, click menu item `Tools > Import collider workshop`
# Controls
| Control      | Use               |
|--------------|-------------------|
| G            | Generate collider |
| Tab          | Next sprite       |
| Shift+Tab    | Prev sprite       |
| Left arrow   | Prev collider     |
| Right arrow  | Next collider     |
| Ctrl+S       | Save              |
| Right click  | Split collider    |
| Middle click | Pan               |
| Scroll       | Zoom              |
| Space        | Prevent editing   |
